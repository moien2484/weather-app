## 🧠 About The Project

*Weather App* is a responsive and user-friendly web application that allows users to check real-time weather conditions for any city in the world.  
Built with *React + JavaScript*, it fetches live data from the OpenWeatherMap API and displays temperature, humidity, wind speed, and more.

---

## 🚀 Features

- 🌎 Search Weather by City Name  
- 🌡️ Shows Temperature, Humidity, and Wind  
- ⏳ Loading Indicator While Fetching  
- ☀️ Dynamic Icons Based on Weather  
- 🧠 Type-Safe Logic using TypeScript  
- 📱 Responsive & Mobile-Friendly Design
